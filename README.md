# SmartAgri — Smart Agriculture Research Website (HTML + CSS Only)

This version uses **HTML and CSS only**. There are no JavaScript files, inline scripts, frameworks, package installations, or build steps.

## Open the website
1. Extract `Smart_Agriculture_Research_Website_HTML_CSS.zip`.
2. Keep all HTML pages and `styles.css` in the same folder.
3. Open `index.html` in a browser.

## Main navigation pages
- `index.html` — Overview
- `domain.html` — Domain overview and five topic links
- `milestones.html` — Research timeline
- `deliverables.html` — Official Documents and Presentations (Slides)
- `about.html` — Supervisors and undergraduate researchers
- `contact.html` — Contact details

## Domain subpages
- `literature-survey.html`
- `research-gaps.html`
- `problem-objectives.html`
- `system-components.html`
- `technologies.html`

## Edit the website
Open the relevant HTML file in VS Code or another text editor:
- Edit text and links in the corresponding page.
- Edit all colours, spacing and responsive layout in `styles.css`.
- Replace researcher placeholders with the correct names.
- To add a team photo, replace an initials block with `<img src="assets/team-name.jpg" alt="Person name">` and keep the image inside `.person-avatar`.
- Replace `href="mailto:"` on `contact.html` with `href="mailto:your-team-email@example.com"`.

## Drive documents
Drive links were inserted from the links supplied in chat. Preview/download availability depends on the Drive permissions and Google Docs/Slides settings. If a preview/export link is blocked, use the original Drive link.

## Important
- Check List document links were not included because they were not supplied yet; add them to `deliverables.html` when available.
- Three researcher names are placeholders.
- The domain and milestone descriptions are a draft summary; verify against the final proposal and PP1/PP2 before submission.
- The project content can be updated by editing HTML; no CMS or scripting is needed.
